# سایت شخصی زهرا زوبونی

یک سایت شخصی تک‌صفحه‌ای، فارسی، راست‌چین و responsive برای انتشار روی GitHub Pages.

## فایل‌ها
- `index.html` ساختار صفحه
- `style.css` طراحی و responsive
- `script.js` منوی موبایل و سال فوتر

## عکس پروفایل
در نسخه فعلی به‌جای عکس واقعی، یک آواتار ساده با حرف «ز» قرار داده شده است. بعداً می‌توان فایل عکس را در پوشه پروژه قرار داد و بخش `.profile-placeholder` را با `<img>` جایگزین کرد.
